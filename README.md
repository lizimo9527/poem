# 古诗词赏析网站

一个基于 Vue 3 + TypeScript 的古诗词赏析网站，展示中国古典诗词的优美与智慧。

## 功能特性

- 📚 **诗词浏览** - 浏览精选古诗词作品
- 👨‍🎓 **诗人介绍** - 了解著名诗人的生平与成就  
- ⭐ **收藏功能** - 收藏喜欢的诗词作品
- 📱 **响应式设计** - 适配各种设备屏幕
- 🎨 **优雅界面** - 传统与现代结合的设计风格

## 技术栈

- **前端框架**: Vue 3 + TypeScript
- **构建工具**: Vite
- **路由管理**: Vue Router
- **状态管理**: Pinia
- **样式**: CSS3 + 响应式设计

## 项目结构

```
src/
├── components/     # 可复用组件
├── views/          # 页面组件
├── data/           # 静态数据
├── types/          # TypeScript 类型定义
├── stores/         # 状态管理
├── utils/          # 工具函数
└── router/         # 路由配置
```

## 快速开始

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

3. 构建生产版本：
```bash
npm run build
```

## 页面说明

- **首页** (`/`) - 网站介绍和功能概览
- **诗词浏览** (`/poems`) - 浏览所有诗词作品
- **诗人列表** (`/authors`) - 查看诗人信息
- **我的收藏** (`/favorites`) - 管理收藏的诗词

## 数据说明

诗词数据包含以下字段：
- 标题、作者、朝代
- 原文内容
- 现代译文
- 诗词赏析
- 标签分类

## 环境配置

复制 `.env.example` 文件为 `.env` 并配置您的 Supabase 项目信息（如需使用数据库功能）。
